# Nero Connect

Independent local macOS pilot. Do not modify the installed NeroNook host or its
other plugins. Keep service-specific auth/network/storage here; no backend SDK
dependency belongs in the generic NookPluginSDK. Native app and probe build
independently. macOS 14+, SwiftUI, CryptoKit and device-only Keychain storage.
Use the official pinned Auth client. No administrator key in clients, credentials
in logs/reports, browser-token import, public release or paid service upgrades.
Only user-authored sample notes are synced in this slice. No calendar, credential,
audio, screen, clipboard or remote action export. Preserve failed receipts and
distinguish same-Mac processes/VMs from actual owner acceptance on two Macs.
